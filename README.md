# train-datasets
“Practiced data preprocessing and exploration using Pandas in Jupyter Notebook"
📊 Dataset Exploration in Jupyter
📌 Project Overview

This project focuses on basic dataset exploration using Python libraries in Jupyter Notebook. I practiced key functions to understand and summarize a dataset.

🛠️ Steps Covered

🔎 info() – to check column names, data types, and non-null values

📊 describe() – to get summary statistics (mean, std, min, max, etc.)

👀 head() – to preview the first few rows of the dataset

👇 tail() – to view the last few rows of the dataset
